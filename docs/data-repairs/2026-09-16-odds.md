## Sources and decisions

Each change, its original row, replacement row, fighter identity, event date and source URL is recorded in [the repair journal](2026-09-16-odds.json).

For the flagged moneylines, both closing prices now come from the same named sportsbook on the archived BestFightOdds event board when available. The fixed preference is DraftKings, BetMGM, Caesars, FanDuel, BetRivers, Unibet, then BetWay. When no named sportsbook pair survives, the source's own archived mean chart supplies both prices. The journal records the book and chart matchup/corner keys. These are source quotes, not newly calculated range midpoints. Existing opening prices were retained.

CJ Vergara–Daniel Lacerda (March 25, 2023) gained opening and closing lines from its verified event-board chart, where the source names the opponent Daniel da Silva. UFC's own [Francisco Figueiredo history](https://www.ufc.com/athlete/francisco-figueiredo) and [Victor Altamirano history](https://www.ufc.com/athlete/victor-altamirano?page=1) confirm the Lacerda/da Silva name usage.

Historical props were recovered using exact event dates/opponents and reviewed source name variants, including former names, transliterations and misspellings. Examples include Cheyanne Buys/Vlismas, Yana Kunitskaya/Santos, Melissa Dixon/Mullins, Yilan Sha/Shayilan Nuerdanbieke, Joe Pfyer/Pyfer, and Carlos Diego Ferreira/Diego Ferreira. Identity evidence includes UFC's [Mullins article](https://www.ufc.com/news/melissa-mullins-i-feel-im-always-underdog-ufc-vegas-90), [Radtke article](https://www.ufc.com/news/charles-radtke-is-in-this-for-legacy-ufc-293), and the Nevada commission's [Culibao–Shayilan bout record](https://boxing.nv.gov/uploadedFiles/boxing.nv.gov/content/results/2021_Results/05-22-21MMA.pdf). These corrections apply to the imported odds only; no fighter profiles were changed.

The four restored round breakdowns are Santos–Wood, Wang–da Silva, Barber–Cerminara, and Vlismas–Martin. Round-market labels use the verified local fighter name so the existing UI assigns the prices to the correct fighter. Each renamed quote retains its original `source_label`.

The remaining entries were left unresolved where no usable quote was found, the source identity was questionable, or an apparent opening-price anomaly could not be conclusively corrected. In particular, the UFC 298 source lists Alexsandre Topuria against Volkanovski; it was not silently treated as Ilia. Archived UFC event-page prices and pre-fight articles were not substituted for verified closing prices. Large genuine/hypothetical opening-to-closing moves remain flagged; Chimaev–Usman's source chart begins in October 2021, two years before their actual bout.

## Validation and recovery

- All 92 changed rows were checked against the repair journal and live database.
- All 693 imported prop markets and 1,955 moneyline/prop prices were verified against downloaded source HTML or decoded source charts.
- Every imported fighter-specific round quote was passed through the client's actual layout function and mapped to its verified fighter.
- SQLite `quick_check` returned `ok`; 20 existing odds parser/chart tests passed.
- The live `/api/bugs` response confirmed the counts above and unchanged counts in every other group.

Raw source pages, charts, preparation scripts and validation scripts are retained in `server/data/odds-repair-2026-09-16.tar.gz` (local data, ignored by Git). Its SHA-256 is in the repair journal. A complete pre-repair SQLite backup is at `/tmp/ufc-odds-audit/before.db`; the journal also preserves the individual original rows for targeted recovery.

Separately, the Bugs page now shows each category's total above its subcategories. The total sums the displayed subcategory counts and follows the existing filter/review controls.
